## 제품 결정 (유지)

- **스펙 = 로컬 웹 Memos** (`web/`). Moe Memos는 축소판 서드파티. 벤치마크 목표 아님.
- 웹에서 되는 일을 앱에서 빼지 않음. 탭/시트만 iOS 관례.
- 계정: 로컬 / 셀프호스트 / 이후 유료 클라우드.
- 메모 본문은 Firestore에 두지 않음. 원본은 Memos 0.30 API.
- 모바일 인증: Keychain PAT. 쿠키 아님.
- 새 앱. Moe Memos 포크 아님 (MPL, App Store 4.1).
- 작성기는 웹 CodeMirror 6를 WKWebView **섬**으로 재사용하는 쪽이 패리티에 가장 가까움. 나머지 SwiftUI.
- 모바일 웹 사용성이 이미 좋음 → 네이티브 전 화면을 한 번에 갈아엎으면 손맛을 잃을 수 있음. 품질 게이트는 **홈+작성기가 localhost:3001 모바일과 동급인지**.

### iOS 메뉴 (폰)
